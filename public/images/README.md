# Portrait

`portrait.jpg` is shown in the hero card (top right) and used as the social
preview image (`og:image` in `index.html`). Its path is `profile.portrait` in
`src/content/content.json`.

- Aspect 4:5, around 900 × 1125 px, JPEG quality ~82, under ~300 KB.
- The card fades to the background at the bottom and overlays a name badge
  there, so keep the face in the upper two thirds.

If the file is missing, the card shows a labelled placeholder instead of a
broken image.
